Explication page par page

signup.html

Créer un compte utilisateur CBC Station.

  • Champs obligatoires : nom complet, email, mot de passe, type de compte
  • Erreurs courantes : email déjà utilisé, mot de passe trop court, champs vides

Explication étape par étape :

  1. Accéder au formulaire : Ouvrez la page signup.html depuis votre navigateur.
  2. Remplir les informations personnelles : Saisissez votre nom complet, email, mot de passe sécurisé et sélectionnez le type de compte : Personnel ou Entreprise.
  3. Vérification email : Après soumission, vous recevrez un email de confirmation pour valider votre compte.
  4. Génération automatique du code de parrainage : Lors de la création du compte, CBC Station génère automatiquement un code de parrainage unique pour chaque utilisateur.
  5. Fonctionnement du parrainage : Ce code peut être partagé avec d’autres utilisateurs. Chaque inscription via votre code vous permet de gagner des avantages (bonus, visibilité, crédits).
  6. Activation du compte : Après vérification email et validation des informations, votre compte devient actif et prêt à publier ou explorer des annonces.
  7. Conseil professionnel : Utilisez une photo de profil claire et un mot de passe complexe pour sécuriser votre compte.

Une fois ces étapes complétées, vous pourrez accéder à votre dashboard et commencer à publier ou explorer des opportunités.

poster.html (IMPORTANT)

  • Uploader un PDF ailleurs
  • Récupérer le lien public
  • Coller le lien dans pdf_url

Explication étape par étape :

  1. Préparer votre PDF : Assurez-vous que le fichier est complet, lisible et correctement nommé.
  2. Uploader le PDF : Utilisez un service d’hébergement public (Google Drive, Dropbox, OneDrive, etc.). Vérifiez que le lien est public et accessible sans authentification.
  3. Récupérer le lien direct : Obtenez le lien de partage public. Pour Google Drive, utilisez la fonction “Obtenir le lien partageable” puis transformez-le en lien direct si nécessaire.
  4. Coller le lien dans CBC Business : Dans le champ pdf_url de la page poster.html, collez le lien exact obtenu.
  5. Vérification : Testez que le PDF s’affiche correctement sur la plateforme après soumission.
  6. Conseils : Utilisez des fichiers PDF de taille raisonnable (<10 Mo) et des noms explicites pour faciliter la recherche et la lecture par les utilisateurs.

Une fois ces étapes réalisées, votre PDF sera accessible à tous les utilisateurs de CBC Business et pourra être utilisé pour vos annonces ou missions.

explorer.html

  • Rechercher et filtrer les annonces par mot-clé, catégorie, province ou niveau de formation
  • Voir les détails des annonces et accéder aux profils des utilisateurs
  • Identifier facilement les annonces urgentes, boostées ou vérifiées

La page Explorer vous permet de parcourir toutes les annonces disponibles sur CBC Business en RDC.

  1. Filtres de recherche :
    • Le champ de recherche permet de trouver des annonces par mots-clés (titre, description, tags).
    • Les menus déroulants filtrent par catégorie, province et niveau de formation requis.
    • Vous pouvez combiner plusieurs filtres pour affiner vos résultats.
  2. Affichage des annonces :
    • Chaque annonce est présentée sous forme de carte avec : titre, description, catégorie, localisation et salaire.
    • Les statistiques (vues, clics, commandes) sont visibles directement sur la carte.
    • Les badges 🔴 Urgent, ⭐ Boost et 🔰 Vérifié permettent de repérer rapidement les annonces prioritaires ou de confiance.
  3. Actions :
    • Le bouton Voir l’annonce redirige vers la page détaillée de l’annonce.
    • Vous pouvez également filtrer dynamiquement depuis l’URL (ex: explorer.html?user=USERID) pour ne voir que les annonces d’un utilisateur spécifique.
  4. SEO dynamique :
    • Le titre et la description de la page s’adaptent automatiquement selon vos filtres pour améliorer la visibilité sur les moteurs de recherche.
    • Exemple : filtrer par catégorie et province mettra à jour le titre pour indiquer “Développement Web à Kinshasa | CBC Business”.
  5. Astuce :
    • Pour une recherche rapide, combinez mots-clés et filtres.
    • Les annonces boostées et vérifiées sont mises en avant, facilitant la sélection des missions fiables.

annonce.html

  • Affichage détaillé d’une annonce sélectionnée depuis explorer.html
  • Affichage en temps réel des statistiques : vues, clics, candidatures et républiées
  • Gestion des badges : Urgent, Boost, Vérifié
  • Actions dynamiques selon l’utilisateur : propriétaire, candidat ou non connecté
  • Formulaire de candidature sécurisé avec vérification des doublons
  • Connexion requise pour postuler ou contacter l’auteur

La page annonce.html est conçue pour offrir une vue complète et professionnelle d’une annonce individuelle. Elle fonctionne de la manière suivante :

  1. Chargement dynamique : L’annonce est récupérée depuis Firebase Firestore en utilisant l’ID passé en paramètre URL.
  2. Badges : Les badges Urgent, Boost et Vérifié sont affichés en fonction des données de l’annonce et du statut de l’utilisateur.
  3. Résumé et description : Toutes les informations essentielles de l’annonce sont affichées (type, niveau, salaire/budget, état, description détaillée).
  4. Statistiques en temps réel : Le nombre de vues, clics, candidatures et républiées est mis à jour dynamiquement et la vue est incrémentée à chaque chargement.
  5. Auteur de l’annonce : Les informations de l’auteur (nom, type de compte, statut, nombre d’annonces) sont récupérées depuis Firestore et affichées de manière professionnelle. Un lien vers ses autres annonces est fourni.
  6. Actions utilisateur :
    • Non connecté : bouton "Se connecter pour postuler".
    • Utilisateur propriétaire : seuls les boutons de gestion (marquer comme rendue) sont visibles.
    • Autres utilisateurs : boutons "Postuler" et "Contacter" affichés.
  7. Sécurité candidature : La page vérifie que :
    • L’utilisateur ne peut pas postuler à sa propre annonce.
    • Une annonce marquée comme rendue ne peut plus recevoir de candidatures.
    • Les doublons sont évités (un utilisateur ne peut postuler deux fois à la même annonce).
  8. Fichiers joints : Les PDF ou documents associés à l’annonce sont accessibles si fournis.
  9. Expérience professionnelle : Les actions, boutons et formulaires sont conditionnels et dynamiques pour offrir une navigation claire et intuitive.

⚠️ Cette page est destinée à un usage professionnel et met en avant la fiabilité, la sécurité et la lisibilité de chaque annonce pour les candidats et les entreprises.

dashboard.html

  • Changer la photo via une URL externe
  • Supprimer et remplacer correctement l’URL
  • Copier son User ID et code de parrainage

Le Dashboard CBC Business est votre centre de gestion personnel. Voici comment l’utiliser efficacement :

  1. Photo de profil :
    • Dans la section "Photo", saisissez l'URL de votre nouvelle image hébergée publiquement (ex : https://exemple.com/photo.jpg).
    • Cliquez sur OK pour mettre à jour la photo. L’ancienne image sera remplacée.
    • Assurez-vous que l’URL est accessible publiquement pour que tous puissent voir votre profil correctement.
  2. User ID :
    • Votre identifiant unique est affiché dans le champ "User ID".
    • Cliquez sur Copier ID pour le copier facilement dans le presse-papier.
    • Ce User ID est nécessaire pour que d’autres utilisateurs vous mentionnent dans leurs rendus ou missions.
  3. Parrainage :
    • Un code de parrainage unique vous est attribué automatiquement.
    • Copiez ce code pour inviter d’autres utilisateurs. Chaque nouveau membre qui s’inscrit avec votre code vous rapporte des avantages et bonus.
    • La section parrainage vous permet de suivre vos gains et referrals directement depuis le Dashboard.
  4. Statistiques :
    • Vous pouvez consulter vos annonces, vues, clics et commandes.
    • Les cartes récapitulatives affichent rapidement vos performances.
    • Des boutons "Voir" permettent d’accéder aux détails complets pour chaque section.
  5. Messages privés :
    • La section chat vous montre toutes vos conversations avec d’autres utilisateurs.
    • Vous pouvez cliquer sur chaque discussion pour lire ou répondre directement.

💡 Astuce : Gardez votre profil complet et votre photo à jour pour améliorer votre visibilité et la confiance auprès des autres utilisateurs.

modifier.html

  • Modifier les informations de l’annonce
  • Consulter les statistiques
  • Effectuer des actions rapides (activer, mettre en pause, voir commandes)
  • Marquer comme rendu ou supprimer l’annonce

La page Modifier l’annonce permet de gérer et mettre à jour toutes vos annonces publiées.

  1. Formulaire de l’annonce :
    • Modifiez le titre et la description pour mieux présenter votre annonce.
    • Choisissez la catégorie, et indiquez le salaire ou budget proposé.
    • Renseignez la ville, province et lieu pour localiser correctement votre offre.
    • Définissez le statut : actif pour visible ou pending pour temporairement fermé.
    • Cliquez sur Enregistrer les modifications pour sauvegarder vos changements.
  2. Statistiques :
    • Consultez le nombre de vues, clics et commandes pour cette annonce.
    • Ces données vous aident à analyser la performance de vos publications.
  3. Actions rapides :
    • Activer : rendre votre annonce visible immédiatement.
    • Mettre en pause : masquer temporairement l’annonce.
    • Voir les commandes : accéder aux candidatures et commandes reçues pour cette annonce.
  4. Marquer comme rendu :
    • Permet de confirmer qu’une mission ou service a été réalisé.
    • Indiquez la note/évaluation pour le client.
    • Entrez le UserID du client (forID) pour associer correctement la livraison.
    • Cliquez sur Marquer comme rendu pour finaliser l’action.
  5. Supprimer l’annonce :
    • ⚠️ Cette action est irréversible et supprime définitivement l’annonce.
    • Utilisez ce bouton uniquement si vous êtes certain de vouloir supprimer l’offre.

💡 Astuce : Avant de modifier ou supprimer, vérifiez les statistiques et commandes pour ne pas perdre de clients ou informations importantes.

commande.html

  • Filtrer les commandes reçues ou envoyées
  • Consulter les détails de chaque commande
  • Effectuer des actions rapides sur chaque commande

La page Commandes permet de gérer toutes vos transactions, qu’elles soient reçues ou envoyées.

  1. Filtres :
    • Le menu Toutes / Reçues / Envoyées vous permet de filtrer rapidement le type de commandes.
    • Le menu Toutes les annonces vous permet de ne voir que les commandes liées à une annonce spécifique.
  2. Résumé :
    • La section Commandes reçues affiche le nombre total de commandes reçues pour vos annonces.
    • La section Commandes envoyées affiche le nombre de commandes que vous avez envoyées à d’autres annonces.
    • Ces chiffres vous donnent un aperçu rapide de votre activité.
  3. Commandes reçues :
    • Chaque ligne du tableau correspond à une commande reçue pour vos annonces.
    • Vous pouvez consulter : l’ID de la commande, l’annonce concernée, le client, la date et le statut.
    • Le bouton Action permet de voir les détails, répondre au client ou marquer comme traité.
  4. Commandes envoyées :
    • Chaque ligne du tableau correspond à une commande que vous avez envoyée à un autre utilisateur ou annonce.
    • Vous pouvez consulter : l’ID, l’annonce cible, le destinataire, la date et le statut.
    • Le bouton Action permet de suivre l’état de votre demande ou d’annuler si nécessaire.
  5. Astuce :
    • Vérifiez régulièrement vos commandes reçues pour répondre rapidement et améliorer votre réputation.
    • Filtrer par annonce ou type vous aidera à gérer efficacement un grand nombre de commandes.

💡 Astuce pro : Combinez les filtres et le résumé pour avoir une vision claire de vos transactions et prioriser vos actions.

chat.html

  • Messagerie privée sécurisée entre utilisateurs
  • Limite de 5 conversations actives par utilisateur pour éviter la surcharge
  • Chaque conversation peut contenir jusqu’à 70 messages par défaut
  • Affichage en temps réel des messages grâce à Firebase Firestore
  • Visualisation du profil du destinataire avec photo, nom et badge vérifié

La page chat.html est conçue pour permettre des échanges privés et structurés entre utilisateurs de la plateforme. Lorsqu’un utilisateur ouvre un chat, le système procède comme suit :

  1. Vérification de l’existence d’un chat entre les deux utilisateurs. Si un chat existe, il est ouvert avec toutes les conversations précédentes.
  2. Si aucun chat n’existe et que la limite de 5 conversations actives n’est pas atteinte, un nouveau chat est créé automatiquement dans la base Firestore.
  3. Les messages sont synchronisés en temps réel. Les messages entrants sont marqués comme "lus" automatiquement pour garantir le suivi des échanges.
  4. Le système respecte la limite de messages (par défaut 70) par chat pour assurer la performance et la lisibilité de la conversation.
  5. Le profil du destinataire est affiché de manière professionnelle avec sa photo, son nom et un badge vérifié si applicable.

⚠️ Cette page est destinée à un usage professionnel : chaque conversation est conservée dans Firestore, et l’utilisateur doit respecter les limites pour assurer la fluidité et la sécurité du service.

Systeme de Parrainage

Système de parrainage CBC Business.

  • Chaque utilisateur dispose d’un code de parrainage unique
  • Le code permet de lier une inscription à un parrain
  • Le parrainage offre des avantages progressifs

Fonctionnement du parrainage

Le système de parrainage CBC Business permet aux utilisateurs de recommander la plateforme à de nouveaux membres tout en bénéficiant d’avantages concrets.

  1. Attribution du code : Chaque compte dispose d’un code de parrainage unique, généré automatiquement et accessible depuis le tableau de bord.
  2. Partage du code : L’utilisateur peut partager son code librement (lien, texte, invitation). Ce code est sa clé d’identification en tant que parrain.
  3. Inscription via le code : Lorsqu’un nouvel utilisateur s’inscrit en utilisant ce code, le système associe automatiquement le compte au parrain correspondant.
  4. Validation : Le parrainage devient actif uniquement après la validation complète du compte du filleul (email confirmé, compte actif).
  5. Avantages : Chaque parrainage validé peut donner accès à des bonus : visibilité accrue, crédits, priorités ou fonctionnalités supplémentaires.

Le parrainage est entièrement automatique et ne nécessite aucune action technique de la part des utilisateurs.

FAQ — Questions fréquentes

Pourquoi mon PDF ne s’affiche pas ?

Assurez-vous que votre PDF est hébergé ailleurs (serveur public, Dropbox, Google Drive public). CBC ne permet pas d’héberger les fichiers directement.

Pourquoi mon lien ne fonctionne pas ?

Vérifiez que le lien est complet et public. Évitez les liens temporaires ou privés.

Pourquoi copier mon User ID ?

Il faut le donner à celui avec qui vous avez conclu une mission pour qu’il vous mentionne correctement dans ses rendus.

Comment modifier mon profil ?

Sur votre dashboard, supprimez l’URL existante de votre photo (toujours hébergée ailleurs), ajoutez la nouvelle URL, et mettez à jour vos informations personnelles.

Où trouver mon code de parrainage ?

Sur le dashboard, dans la section “Parrainage”. Copiez le code et partagez-le pour obtenir des gains et bonus.

Qui contacter en cas de problème ?

Envoyez un email à cbcbusiness59@gmail.com. Nous répondons sous 24h.
